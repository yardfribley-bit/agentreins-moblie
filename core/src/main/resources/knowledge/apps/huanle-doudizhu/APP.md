## 游戏任务
- 先打开欢乐斗地主并检查实际画面、账号和游戏模式；不同版本的界面可能不同，不要依赖固定坐标。
- 已在一台荣耀手机的 8.057.016 版本观察到游戏横屏运行，界面由 Unity 渲染，无障碍树可能只有一个 Game view，不能从空树推断游戏未运行。以当前任务虚拟屏的截图和 OCR 为依据；横屏时坐标以当前画面尺寸与工具坐标系为准。
- 大厅可能出现付费活动、抽卡或广告。先观察标题和关闭按钮；只关闭当前能确定的弹窗，不进入付费活动。点击后检查画面，若误入其他页面返回并重新观察，连续几次不能恢复则停止并说明。
- 画面、牌面和出牌按钮必须能辨认清楚才操作。无障碍树缺失时可结合当前截图；牌面无法可靠辨认、轮次不确定或画面未变化时停止并告知用户，不要猜牌或连续点击。
- 每次操作前确认轮到自己，记录可见手牌、上家出牌和当前可选动作；出牌后重新观察，确认手牌或轮次确实发生变化。
- 牌局有倒计时。优先处理当前一手，不要在每次选牌后额外反复截图或做长篇分析；但只可使用当前画面能确认的按钮和牌。若牌面、按钮或回合无法及时确认，明确报告无法可靠操作，不要盲点。
- 超时可能自动进入托管，系统出牌不是助手出牌。看到“取消托管”说明当前处于托管；只在用户要求自己操作时尝试取消并重新观察。不要根据角色、手牌数量或倒计时猜测地主、牌型或胜负。
- 先从用户选择的普通练习模式开始；涉及充值、付费、购买道具或可能造成额外扣费的操作交给用户确认。不要声称必胜或保证战绩。
- 一局结束时记录实际结果、识别困难及失败步骤，为下一局改进提供依据；无法核实结果时明确说明。

这些是初始操作原则，具体界面、牌面识别和策略需要通过实机对局验证，不能当成已经验证的自动玩法。
