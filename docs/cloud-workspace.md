# 云工作台：实施状态和约束

当前应用支持保存一台用户提供的 SSH 主机、核对主机身份，以及向任务提供有时限的 SSH 命令工具。手机和服务器能否连接必须在实际设备上验证；配置存在不代表连接成功。命令的超时或连接断开不代表远端进程已经停止。

持久化云任务尚未实现：不能把手机端定时任务、SSH 连接或一次短命令说成云端长期执行。应用尚未提供任务部署、跨重启恢复、任务取消、云端结果同步到 Obsidian 的完整链路。

后续执行器应保存在用户主机的独立目录，持久化任务、运行记录和结果；区分排队、运行、完成、失败、等待手机和取消等状态。重启恢复时，对未确认的外部动作不得盲目重复。手机只在用户明确授权的范围内安装和管理执行器，任务和凭据不得写死到应用。用户要求操作手机 App 的步骤仍需手机在线及对应账号会话。

参考：GitHub 的自托管运行器需要在主机上运行执行程序，并由拥有者负责环境与更新；Temporal 的持久化执行通过保存历史支持跨进程恢复。两者提供设计参考，不代表本项目已经具备相同保证。
