# 设置手机操作：一步一步来

简体中文 | [English](setup-guide.en.md)

这份指南带你走完 Mika 里的「设置手机操作」。不需要懂技术，照着做就行，大约 3 到 5 分钟。

## 先了解一下

- **要什么**：一台安卓 13 及以上的手机（低于 13 能装 Mika，但不能操作 App），连着任意一个 Wi-Fi（不用能上网，连上就行）。
- **为什么要这一步**：Mika 在一块看不见的「后台屏」上替你点 App，你照常用自己的屏幕。要做到这一点，Mika 需要借用安卓自带的「无线调试」启动一个内置的小助手。
- **全在手机上完成**：不需要电脑，也不需要数据线。
- **只做一次**：配对一次之后，Mika 会自己连接；以后就算系统把无线调试关了，Mika 也会在你允许的前提下把它重新打开。
- **不设置也能用**：上网查资料、处理文件、聊天都不受影响；只有要操作手机 App 时才需要它。

> 下面写的路径按安卓原版系统。有的手机菜单名字或位置不一样，找不到时可以在系统设置顶部的搜索框里搜关键字（比如「版本号」「开发者选项」「无线调试」）。

## 在哪里打开向导

- 第一次打开 Mika 时，配好模型后的最后一步就是「设置手机操作」。
- 当时点了「稍后再说」也没关系：打开 Mika 的设置，点顶上状态卡片里的提示即可进入；或者进 设置 › 手机操作 › 重新配对。
- 任务要用手机而还没设置时，对话里也会出现一行提示，点「去设置」即可。

向导是一张有编号的清单，一共六步。**做完一步会自动打勾**，Mika 会自己检查系统开关，一般不需要点「下一步」。当前这一步会亮起并带一个按钮，点它会直接跳到系统里对应的设置页；做完后按返回键回到 Mika 就行。

有的手机读不到、或读不准这些开关：明明打开了，Mika 还停在这一步。这时点这一步下面的「我已经打开了,下一步」继续就行，向导不会把你卡住。最后以配对、连接成功为准：连上了就算设置好了。已经打勾的步骤可以点一下，回去重做。

## 第 1 步：打开开发者选项

**在 Mika 里**：点「打开关于手机」。

**在系统里**：

1. 来到 设置 › 关于手机。
2. 一直往下滑，找到「版本号」。
3. **连续快速点「版本号」7 次**。中途会提示「再点几次就进入开发者模式」；如果手机设了锁屏密码，会让你输一次密码。
4. 看到「你已处于开发者模式」（或类似的提示）就好了。

<!-- 截图：关于手机页面里的「版本号」 -->

**怎么知道成功了**：回到 Mika，第 1 步显示「已打开」并打勾。

**常见问题**：

- 找不到「版本号」：有的手机放在「关于手机」里面的「软件信息」或「版本信息」里。也可以在设置里搜「版本号」。
- 点了没反应：要连续点，中间不要停太久。
- 提示「已处于开发者模式」：说明之前开过了，直接回 Mika。
- 明明开了，Mika 还停在这一步：点「我已经打开了,下一步」继续。

## 第 2 步：打开 USB 调试

**在 Mika 里**：点「打开开发者选项」。

**在系统里**：

1. 来到 设置 › 系统 › 开发者选项（Mika 会直接带你过来）。
2. 往下找到「USB 调试」，打开开关。
3. 弹出「允许 USB 调试吗？」时点「确定」。

<!-- 截图：开发者选项里的「USB 调试」开关 -->

**不需要插数据线**。打开它的作用是：配对好以后，就算断开 Wi-Fi，Mika 也能继续操作手机。

**怎么知道成功了**：回到 Mika，第 2 步打勾。

**常见问题**：

- 找不到「开发者选项」：安卓原版在 设置 › 系统 里面；有的手机放在「更多设置」「其他设置」里。在设置里搜「开发者选项」最快。
- 以后请**一直开着** USB 调试，关掉后手机操作会停下。
- 明明开了，Mika 还停在这一步：点「我已经打开了,下一步」继续。

## 第 3 步：打开 Mika 的无障碍（建议先跳过）

**建议：直接点「跳过(配对后 Mika 会自己打开)」**，它就是这一步最上面那个按钮。

为什么建议跳过：

- 配对完成后，Mika 会**自己**把它的无障碍服务打开（设置 › 恢复与修复 里的「替我打开无障碍」默认就是开着的），你不用去系统里找。
- 自己打开反而容易卡住：如果 Mika 不是从应用商店装的（比如从网页下载的安装包），安卓会把无障碍标成「受限制的设置」，不让直接打开。由 Mika 配对后自己打开，就不会遇到这个限制。

跳过的代价只有一点：下一步配对时要你自己填一次 6 位配对码（很简单，见第 5 步）。

<!-- 截图：无障碍一步的「跳过(配对后 Mika 会自己打开)」按钮 -->

**如果你已经开过无障碍**：这一步会自动打勾，配对时 Mika 会自己读出配对码，更省事。

**如果你一定要现在手动打开**：点「去无障碍设置」，在列表里找到 Mika，打开开关并确认。如果开关是灰的、或提示「受限制的设置」：

1. 先回到 Mika，点「打不开？先去应用信息里允许受限制的设置」（或者自己去 设置 › 应用 › Mika）。
2. 在「应用信息」页右上角点 ⋮（三个点），选「允许受限制的设置」，按提示确认。
3. 再回到无障碍设置，打开 Mika。

<!-- 截图：应用信息右上角 ⋮ 菜单里的「允许受限制的设置」 -->

> 注意：⋮ 菜单里的「允许受限制的设置」，要你**先试着打开过一次**无障碍、被系统拦下之后才会出现。

## 第 4 步：打开无线调试

**先确认手机连着 Wi-Fi**（不需要能上网）。

**在 Mika 里**：点「打开开发者选项」。

**在系统里**：

1. 在开发者选项里往下找到「无线调试」，打开它右边的**开关**。
2. 系统问「要允许在此网络上进行无线调试吗？」时：**勾上「始终允许使用此网络」**，再点「允许」。勾上后，以后在这个 Wi-Fi 上 Mika 就能自己打开无线调试。

<!-- 截图：开发者选项里的「无线调试」 -->
<!-- 截图：「允许无线调试」弹框和「始终允许使用此网络」勾选框 -->

**怎么知道成功了**：回到 Mika，第 4 步打勾。

**常见问题**：

- 开关打开后自己又关了：多半是没连 Wi-Fi，或者在弹框里没点「允许」。连上 Wi-Fi 再开一次。
- 开关明明开着，Mika 还停在这一步：有的手机读不到这个开关，点「我已经打开了,下一步」继续。

## 第 5 步：用配对码配对

**先说最容易出错的一点**：配对码只在系统的配对窗口开着时有效。**窗口一关（切到别的 App、按返回、锁屏），这个码就作废了**。所以填码时请留在配对窗口上，不要切换 App。

**开始前**：Mika 到这一步会请求「发通知」的权限，请点「允许」——没有无障碍时，配对码就是填在 Mika 的通知里的。通知没开时，这一步最显眼的按钮就是先把它打开：

- 没允许 Mika 发通知：向导写着「配对码要在通知里填，先允许 Mika 发通知。」，点「允许通知」。
- 允许了，但 Mika 的「配对」这一类通知被关掉了：点「打开「配对」通知」，在系统的通知设置里打开它。
- 「配对」通知被调成了不弹出：向导会提醒一句，点「去打开」，打开「在屏幕上弹出」；不打开也行，下拉通知栏照样能填。

**在 Mika 里**：点「去无线调试」。

**在系统里**：

1. Mika 会带你到开发者选项，并标出「无线调试」那一行。**点「无线调试」这几个字**（不是开关），进入它的页面。
2. 点「使用配对码配对设备」。
3. 屏幕上弹出一个窗口，里面有 **6 位数字的配对码**，还有「IP 地址和端口」。

<!-- 截图：无线调试页面里的「使用配对码配对设备」 -->
<!-- 截图：显示 6 位配对码的配对窗口 -->

接下来分两种情况：

### 情况 A：无障碍已经开着 —— 什么都不用做

Mika 的向导会显示绿色的提示「看到配对码后稍等几秒，Mika 会自己读出来并完成配对」。停在配对窗口上**等几秒**，Mika 会自己读出配对码并完成配对，窗口会自己关掉。

### 情况 B：无障碍没开（跳过了第 3 步）—— 在通知里填码

向导里这一步会画出三小步：① 点「使用配对码配对设备」 ② 屏幕顶部弹出 Mika 的通知；没看到就下拉通知栏 ③ 点「填配对码」，输入 6 位数字。具体是：

1. **不要离开配对窗口**，记下那 6 位数字。
2. 配对窗口一出来，屏幕顶部就会弹出 Mika 的通知「输入配对码」，下面写着「把屏幕上的 6 位数字填在这里，不用离开配对窗口」。没人填的话，它会隔一会儿再弹，最多再弹三次。
   - 如果通知没有弹出来，或者一闪就收起了：**从屏幕顶部往下拉**，打开通知栏，就能看到它。下拉通知栏不会关掉配对窗口。
3. 点通知上的「填配对码」，会出现一个写着「6 位数字」的输入框。
4. 填上那 6 位数字，点发送（输入框右边的箭头）。带空格、横线或全角数字都没关系。
5. 通知变成「正在配对…」，几秒后变成「配对成功」，过一会儿自己消失。

<!-- 截图：通知栏里 Mika 的「输入配对码」通知和输入框 -->

**小提示**：

- 先允许 Mika 发通知。没允许的话，向导里会有提示和「允许通知」按钮。
- 向导里如果出现一条橙色提示，说「需要你处理」和「任务结果」的通知不会弹出：这说的是以后任务里的通知，和配对无关。可以点「去打开」，也可以先不管。
- 填的不是 6 位数字：通知马上提示「要填 6 位数字，再填一次」，输入框还在，不会拿去试。
- 码不对或过期了：通知提示「配对码不对或已失效：在配对窗口重新点「使用配对码配对设备」拿新的码，再填一次」，输入框还在，拿到新码直接填。配对窗口已经关了也一样：回到「无线调试」再点一次「使用配对码配对设备」，会出现**新的**配对码，填新的。
- 实在找不到通知：Mika 向导里有「通知没出来？在这里填」。不过回 Mika 会让配对窗口关掉，所以要用**分屏**：一边显示配对窗口，一边在 Mika 里填。万一 Mika 还没找到配对窗口，它会多要一个数字——配对窗口里「IP 地址和端口」冒号后面的那串数字。

**怎么知道成功了**：回到 Mika，第 5 步显示「已配对」。

这一步没有「下一步」：配对要真的做成。通知和自动读码都不行时，用上面说的「通知没出来？在这里填」。

## 第 6 步：自动连接

这一步不用你做任何事。配对好之后，Mika 会自己连上并准备好，一般几秒钟。看到「手机操作已经设置好了」就完成了。

<!-- 截图：向导显示「手机操作已经设置好了」 -->

如果第 3 步跳过了，这时 Mika 会自己把它的无障碍服务打开。可以在系统的无障碍设置里看到 Mika 已经是打开状态。

Mika 找无线调试的端口时，先试上次连上的、系统给的和局域网里公布的；都找不到时（有的路由器拦着这种公布），它会在这台手机自己身上找一遍，界面上显示「正在本机查找无线调试端口…」，最多十来秒。只找这台手机本身，不碰同一个 Wi-Fi 里的别的设备。

还是找不到时，「自动连接」这一步会出现「填无线调试的端口」：打开系统的「无线调试」页面，看「IP 地址和端口」那一行，把**冒号后面的数字**（比如 `192.168.1.5:41235` 里的 `41235`）填进去，点「连接」。连上之后 Mika 会记住它；关掉再打开无线调试后这个数字会变，Mika 一般能自己找到新的，找不到再填一次就行。

正在连接、连接失败时，底部都有「稍后再说」，随时可以先离开，以后从设置里接着弄。

如果配对或连接没成功，Mika 会按它读到的情况，说出最可能是前面哪一步的问题（比如「「无线调试」好像没开」、「这台手机读不到「无线调试」的开关」），并给一个「回到「打开无线调试」」这样的按钮，点它回去重做那一步。

## 设置好以后

- **USB 调试请一直开着**。关掉后手机操作会停下。
- **无线调试可能会被系统关掉**：安卓在断开 Wi-Fi、换 Wi-Fi、重启手机后会把它关掉。这很正常，Mika 平时用不着它，只有重新启动内置助手（比如重启手机、Mika 更新之后）时才要它开着。设置 › 恢复与修复 里的「自动打开无线调试」「重启后自动恢复」默认开着，Mika 会在连着 Wi-Fi 时替你重新打开，不用再输配对码。
- **第一次到一个新的 Wi-Fi**：系统还没允许在这个网络上无线调试，Mika 打不开它。这时请亲手打开一次「无线调试」，在弹框里**勾选「始终允许使用此网络」**再点「允许」。以后在这个 Wi-Fi 上就不用管了。
- **想重来一遍**：设置 › 手机操作 › 重新配对。
- **不想用了**：设置 › 手机操作 › 解除配对。也可以到系统的 无线调试 › 已配对的设备 里把 Mika 删掉。

## 遇到问题

| 现象 | 怎么办 |
|---|---|
| 找不到「开发者选项」 | 先做第 1 步（在「关于手机」里连点「版本号」7 次）。打开后，安卓原版在 设置 › 系统 › 开发者选项；别的手机可能在「更多设置」等地方，在设置里搜「开发者选项」。 |
| 找不到「版本号」 | 在「关于手机」里往下滑；有的手机在「软件信息」「版本信息」里面。或者在设置里搜「版本号」。 |
| 无线调试的开关打开后自己关掉 | 确认连着 Wi-Fi；打开时弹出的询问框要点「允许」，并勾选「始终允许使用此网络」。换了 Wi-Fi 后要在新网络上再允许一次。 |
| 没看到 Mika 的配对通知 | 先确认允许了 Mika 发通知、「配对」通知没被关掉（向导会提示并给按钮）；从屏幕顶部往下拉通知栏找；还是没有，用向导里的「通知没出来？在这里填」配合分屏。 |
| 配对通知只在通知栏里、不在屏幕顶部弹出 | 「配对」通知被调成了不弹出。点向导里的「去打开」，在系统设置里打开「在屏幕上弹出」；不打开也能下拉通知栏去填。 |
| 提示「配对码不对或已过期」 | 每次打开配对窗口码都会换。回到「无线调试」，重新点「使用配对码配对设备」，填新的 6 位数字。 |
| 提示「配对窗口关掉了」 | 填码时配对窗口要一直开着：不要切 App、不要按返回、不要锁屏。重新打开配对窗口再填。 |
| 配对成功了，但「自动连接」失败 | 确认「无线调试」还开着、手机连着 Wi-Fi，然后点「重试」。还不行就点「重新配对」。向导指出了可能有问题的一步时，点「回到「…」」回去重做。 |
| 一直停在「自动连接」/ 找不到无线调试的端口 | 关掉再打开「无线调试」后点「重试」；换用手机热点或家里的 Wi-Fi（有的路由器拦着设备互相发现）；或者在「填无线调试的端口」里填「无线调试」页面上「IP 地址和端口」冒号后面的数字，点「连接」。 |
| 开关明明打开了，向导还停在那一步 | 有的手机读不准开关，点「我已经打开了,下一步」继续；最后以配对、连接成功为准。 |
| 提示「这个 Wi-Fi 还没允许无线调试」 | 亲手打开一次「无线调试」，弹框里勾选「始终允许使用此网络」再点「允许」。 |
| 提示「没有连上 Wi-Fi」 | 连上任意一个 Wi-Fi（不用能上网），Mika 会自己恢复。 |
| 提示「配对失效了」 | 重新配对一次。在开发者选项里打开「停用 adb 授权超时功能」，以后就不会再失效。 |
| 无障碍里 Mika 的开关是灰的 / 提示「受限制的设置」 | 推荐的做法：跳过这一步，配对后 Mika 会自己打开。要手动打开的话：先试着打开一次被拦下，再去 设置 › 应用 › Mika，右上角 ⋮ › 允许受限制的设置，然后回无障碍设置打开 Mika。 |
| 配对后无障碍还是没打开 | 确认 设置 › 恢复与修复 里「替我打开无障碍」是开着的，等几秒；还不行就按上一行手动打开。 |
| 卡住了，上面都对不上 | 点向导底部的「复制诊断信息」（失败时出错的那一步里也有；也可以在 关于 Mika › 反馈问题 里找到），看一眼内容再点「复制」或「分享」，发给作者（微信或 GitHub 问题）。里面有版本、机型、每一步的状态和最近一次出错的原因，不包含 API Key、聊天内容和屏幕内容。 |
